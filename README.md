# Classic Color Meter

[Classic Color Meter](https://www.ricciadams.com/projects/classic-color-meter) is an enhanced replacement for Apple's Digital Color Meter.

## Philosophy

This repository is publicly-viewable in the hopes that its source code can help others.

Classic Color Meter is feature-complete and closed to outside contributions.
